# 🎾 MOTION TENNIS 3D

## 現在の版 — 2.1.0

最初の画面は Three.js の立体コートです。シングルス練習、CPUダブルス、オンライン1対1、オンライン4人ダブルスを選べます。従来の2Dモードも画面上部から開けます。

### カメラで遊ぶ

1. HTTPS の公開URL、または `http://localhost:3000` で開きます。
2. 「カメラ開始」を押し、ブラウザのカメラ利用を許可します。クリック時に全画面を要求します。未対応・拒否の場合はブラウザ内で画面いっぱいに表示します。「全画面を終了」または Esc で戻れます。
3. 肩と腰、両手がカメラに入る位置で約1秒静止します。「体を認識中」が目印です。立ち位置を変えたら「中心位置を再設定」を押してください。
4. 左右に体をずらして移動、カメラへ近づいて前進、離れて後退。左右が逆なら反転ボタンで切り替えます。
5. 両手を上げてトスし、その後片腕を振ってサーブします。振る左右方向で狙い、肩幅で正規化した手首の速度で強さが変わります。ラリー中も同じ操作で返球できます。約160msの先行スイング受付があります。

キーボードは WASD / 矢印で移動、Shiftでダッシュ、Tでトス、Q / Spaceで打球、Eでロブ、Fでスマッシュ。通常画面にはタッチボタンもあります。7点先取・2点差の簡易ルールで、正式なテニスの全ルールは再現していません。

### オンライン対戦

同じモード・部屋コードで入室し、2人または4人揃ってから1Pが開始します。「招待リンクをコピー」でモードと部屋を共有できます。ダブルスは1P+3P 対 2P+4Pです。ホストが物理・得点を計算し、参加者は入力だけを送ります。相手の位置・ボールは描画時に補間し、自分の移動は端末で予測します。

ホストはゲーム画面を開いたままにしてください。退出・切断時は試合を止めてロビーへ戻り、人数が揃ったら再開できます。3Dと旧2Dのルームは混在できません。公開には既存の Node WebSocket サーバーまたは Cloudflare Worker + Durable Objects が必要です。静的サイトだけではオンライン対戦できません。Gitへのpushとサーバーへのデプロイは別の操作です。

### 反応速度と制約

- 姿勢認識はWeb Workerで処理し、画像を1枚ずつ渡して古いフレームの待ち行列を作りません。ゲーム物理は60Hz、入力・状態通信は最大約30Hzです。Worker非対応時は互換モードに切り替えます。
- MediaPipeのモデル・WASMを外部配信元から取得するため、初回は読み込み時間が必要です。取得できない場合は「簡易認識」と明示し、左右移動と固定強度ショットのみ対応します。
- 画像は端末内で解析し、保存・送信しません。画面には映像を表示せず、認識状態だけを表示します。停止・画面離脱でカメラを解放します。
- カメラが止まったり体が見えなくなった場合は操作を解除します。遅延ゼロや正確な動作コピーを保証するものではなく、光量・画角・端末性能・通信状態によって変わります。
- 「認識 ms」はフレーム取得後の処理時間、「通信往復 ms」はサーバー往復時間です。どちらも体を動かして画面に反映されるまでの全遅延ではありません。

### 開発・確認

`npm install` → `npm run dev`。検証は `npm run lint`、`npm test`、`npm run build`。テストには姿勢ランドマークの合成入力、打球方向・強さ、追跡喪失、先行打球、部屋の分離、実WebSocketによる2人/4人接続・入力・状態転送・退出を含みます。実カメラと全画面のブラウザ実機確認は別途必要です。

参考: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js)、[Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)。

## 旧版の変更履歴

元のテニスゲームを残したまま、**オンラインダブルス・カメラ操作・伝説級CPU**を追加した拡張版です。

## v1.7 — カメラの動きへの反応を向上

- **姿勢認識の確認間隔を短縮**：従来の約20回/秒から、対応環境で最大約30回/秒を目標に処理します。端末・カメラ性能によって実際の回数は変わります。
- **小さな体の移動も認識**：左右方向は標準で約6%、新しい「高感度」で約3.8%、「最大」で約2.5%の画面幅相当の差を判定します（自動調整とヒステリシスあり）。
- **前後移動が反応しやすい**：肩幅変化で前進・後退を判定するしきい値を下げました。
- **腕を振る動作を敏感に**：手首の動きから肩の動きを差し引いてショットを判定。体ごと移動しただけで誤って打たないようにしました。
- **ショット入力の取りこぼし対策**：通常の3D風モードでは約0.32秒、ダブルスでは約0.3秒、スイング入力を受け付けるようにしました。ボールに少し早く合わせて振っても有効になりやすい設計です。
- **走っている動きへの反応**：速い左右移動でダッシュし、オンラインダブルスでもダッシュ中に継続して速く移動します。
- **感度設定を追加**：カメラの操作欄から「標準」「高感度（初期値）」「最大」を選べます。反対方向へ動く場合は「左右の向きを反転」を押します。
- **中心位置を再設定**：立ち位置を変えた場合は「🎯 中心位置を再設定」を押し、約1秒まっすぐ立ってください。
- **プライバシーはそのまま**：顔や体の映像は表示されず、ゲームサーバーにも送信しません。姿勢認識は端末内、モデル取得のみ外部ネットワークを使用する場合があります。

**注意**：高速かつ高精度に反応するには、MediaPipe姿勢認識が有効である必要があります。画面が「簡易認識中」の場合は左右移動とショット中心の簡易判定になるため、前後移動・ロブなどは認識できません。壁や家具から距離を取り、明るい場所で上半身と腕が十分に映るようにしてください（映像プレビューは表示されません）。

## v1.5 — カメラで姿を映さないプライベート操作モード

- **映像プレビュー非表示**：カメラの映像・自分の姿・骨格線はゲーム画面に一切描画しません。カメラの映像拡大ボタンも廃止しました。
- **操作認識は引き続き有効**：ブラウザのカメラ許可後、映像を端末内部で解析し、左右移動・前後移動・ショット・ロブなどを操作できます（対応するモードのみ）。
- **認識状況だけ表示**：カメラの開始/停止、姿勢認識状態、「左へ」「ショット」などの操作名だけを表示します。実際の映像をモニターに出しません。
- **プライバシー**：カメラ画像をアップロードしたり対戦相手に送信したりするコードはありません。姿勢検出モデルの読み込みにはインターネット接続が必要な場合があります。
- **3D視点モード・4人ダブルス**：両モードのカメラ操作に適用されます。

## v1.4 — 3D視点コートモード（前回の追加）

- **サーブ対応**：Rキー、またはサーブ時にショット操作で開始できます。

- **走ると速く移動**：Shiftまたはカメラの大きな動きでダッシュできます。
- **カメラ操作も利用可能**：姿勢認識により、左右移動・前後移動・ショット・ロブ・ダッシュに対応します。

## できること

- **元のゲーム**：ローカル2人プレイ / CPU（かんたん・ふつう・つよい） / 2人オンライン対戦。元のプレースタイル・努力値・さまざまなショットも残っています。
- **伝説級CPU**：元の試合の対戦相手に、最上位のCPUを追加。高い移動速度、正確な予測、ほぼミスなし。
- **4人オンラインダブルス**：1P＋3P（レッドチーム）対 2P＋4P（イエローチーム）。4人が別々のブラウザ・端末から参加。ホスト（1P）が試合開始・ボールの計算を担当し、残り3人は各自のキャラクターを操作できます。
- **ダブルス練習**：CPU3人を相手・味方にしたソロ練習と、強力な「伝説級AIに挑戦」。
- **カメラ体感操作**：カメラに全身の上半身を映し、左右への移動と腕の動きでプレイ（ロブ・ジャンプも対応）。精密な姿勢認識にはMediaPipeのモデルを使い、取得できない場合は簡易的な映像動作判定に切り替えます。**カメラ画像や音声をオンラインに送信しません。**
- **ダブルス追加アクション**：ダッシュ、ロブ、パワーゲージ、必殺スマッシュ、7点先取、連続ラリーと最高ラリー表示、タッチ操作。

## インストール / 起動

Node.js **20.19+ または 22.12+** を推奨します。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。最初の画面は全画面の3D風テニスゲームです。画面上部の **「👥 オンラインダブルス（4人）」** ボタンから新しいモードへ入れます。

> ⚠️ HTMLファイルを直接開いても動作しません。Node.jsまたはCloudflare Workersなどの配信サーバーが必要です。インターネット上の別の場所にいる人と遊ぶには、サーバーを**公開**し、全員が同じURLにアクセスする必要があります。

## ダブルスをオンラインで遊ぶ

1. ホストになる人が「オンラインダブルス（4人）」を開き、部屋コードを確認して「ルームに参加」を押します。
2. 「招待リンクをコピー」で他の3人に送ります。リンクは `?doubles=1&room=DB1234` のような形式です。
3. 残りの人はリンクを開いて「ルームに参加」を押します。全員 **同じ公開サーバー**に接続してください。
4. ロビーに **4/4人** 集まると1Pの「試合開始！」ボタンが使えるようになります。
5. レッド（1P/3P）とイエロー（2P/4P）で勝負。先に7点取れば勝利です。

オンラインダブルスは4人の参加が必要です。3人以下で遊びたいときは「CPUと練習」が使えます（練習はローカルのCPU対戦です）。

### ダブルスの操作

| 操作 | キーボード | カメラ操作 |
|---|---|---|
| 移動 | WASD / 矢印 | 体を左右に動かす、カメラに近づく・離れる |
| 通常ショット | Q / Space / / | 手・腕を振る |
| ロブ | E / `\` | 両手を高く上げて腕を動かす |
| パワースマッシュ | F（パワー90以上） | ジャンプ＋手を振る（カメラ認識時） |
| ダッシュ | Shift | 大きめの左右移動 |

ショットを打つごとにパワーゲージが増え、90以上で強力なスマッシュを打てます。スマホ・タブレット向けに画面下にタッチボタンも付けています。

**元のゲーム**：A / D=移動、W=ジャンプ、Q=ショット、E=ロブ。CPU戦と2人オンラインでは矢印キーも使えます。Shiftで短い高速移動ができます。

## カメラモードの使用方法

1. **PCのカメラ、またはスマホのカメラ**が使用できることを確認します。
2. 元のゲームは画面上部の「📷 カメラ体感操作」、ダブルスは「📷 カメラ操作を使う」を押します。
3. 「カメラ開始」→ブラウザのカメラ使用を許可します。
4. 画面中央に立つと身体の位置をキャリブレーション。立ち位置が変わったら「中心を再設定」を押します。
5. 腕を振ると打球、体を動かすと移動します。必要ならキーボードも併用できます。

高精度の姿勢認識には、初回実行時に外部サービス（jsDelivrのMediaPipe JS/WASM、Google配信の姿勢認識モデル）への**ネット接続が必要**です。失敗した場合は「簡易動作認識」に自動切り替えます。簡易モードは動きの量による判定のため、照明や背景によって精度が落ち、ロブ・ジャンプなどすべての動きを認識できるわけではありません。

**カメラの注意**：HTTPS または `http://localhost` で起動してください。通常の LAN 内 `http://192.168...` では、多くのブラウザでカメラ許可が出ないため、HTTPSの公開URLを使います。カメラ映像はPC・スマホ内だけで処理し、録画もWebSocket送信もしません。壁や家具から距離をとって小さい動きでプレイしてください。

## Cloudflare Workers で公開する

Cloudflare Workers + Durable Objects を使い、WebSocketルームを動かします。**Cloudflare Pagesの静的サイトだけではオンライン対戦は動きません。**

```bash
npm install
npx wrangler login
npm run cf:deploy
```

Workers の公開URLに全員が接続すれば、2人対戦と4人ダブルスで遊べます。Workers無料枠にはリクエスト数などの制限があります。

## Render / Railway / VPS など Node.js サーバー

```bash
npm install
npm run start:prod
```

`PORT` 環境変数に対応。HTTPSで公開する場合、WebSocketも自動的にWSSを使用します。

## v1.6 — 通常の画面いっぱい表示・HDコート・揺れを抑えた動き

この版では**起動すると通常プレイが画面いっぱいに表示**されます。横の設定パネルや余白はありません。ブラウザのタブまで隠したいときだけ、右上の「⛶ 全画面」を使ってください（Escで戻れます）。

- **高解像度コート**：以前使用していた340×340の背景を引き伸ばす方式をやめ、元画像の青空・緑のコート・赤いフェンスを参考に、Canvasで高精細に描き直しました。拡大してもネットや白線がぼやけにくくなります。
- **解像度の自動調整**：Canvasの内部描画サイズを画面サイズ・端末のdevicePixelRatioに合わせて更新します。負荷を抑えるため最大約4K相当に制限します。
- **自然なアニメーション**：走る/歩くときは移動した距離に応じて足が動きます。停止中は足やラケットが周期的に揺れません。ボールには短い軌跡と光を追加しました。
- **CPUの位置揺れを抑制**：移動目標の近くで微妙な行き来をしないように、停止判定と移動距離の制限を追加。視点の左右移動も追従を滑らかにして急な揺れを軽減しました。
- **オンラインダブルスの相手表示**：相手プレイヤーの座標を受信する間隔で画面上の人物がカクつかないよう、描画位置を補間しました。通信とゲームの物理座標はそのまま維持しています。
- **カメラ**：v1.5に引き続き、**自分の姿や骨格線は画面に表示しません**。動きだけを操作へ反映できます。右側の「📷 カメラ操作」で開始操作をしてください。
- **ボタン**：「？操作」「カメラ操作」「やり直す」「ダブルス」「全画面」はコートの上に小さく重ねています。

### 注意点

今回の通常モードは、**透視投影で奥行きを表現したCanvasベースの3D風テニス**であり、WebGLの立体モデルによる完全な3Dシミュレーションではありません。オンラインダブルスのコートは元の表示形式のままです。公開済みのCloudflare Workersに反映するには、再デプロイが必要です。
