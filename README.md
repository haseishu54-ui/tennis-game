# Motion Tennis 3D

カメラの動きで操作する3Dテニス。トップページの index.html がゲーム本体です。

## 遊び方

「プレイ開始」でカメラを許可してください。振る方向がコース、速さがショット・サーブの強さになります。感度調整と「位置を再調整」で調整できます。全画面が拒否された場合は画面の「全画面」を押してください。

CPU対戦、シングルス、ダブルスに対応。オンラインではホストが「新しい部屋」を作り、他の人は同じ6文字コードで参加します。最大4人、不足人数はCPUです。ホスト退出時は部屋を作り直してください。

カメラはHTTPSまたはlocalhostで使用します。映像は端末内だけで処理し、送信しません。簡易画像差分認識のため、明るさ・背景・端末性能により精度と遅延が変わります。「処理 ms」は画像処理時間で、全体の遅延ではありません。

オンラインにはPeerJSの公開シグナリングとWebRTCを使用します。TURN中継は未設定のため、回線によって接続できない場合があります。

## 起動・公開

npm install → npm run dev でローカル起動します。
ビルドは npm run build。Cloudflareへの公開は npm run cf:deploy（認証が必要）です。
任意の静的ホスティングにも dist/ を配置できます。独自のWebSocketサーバーは不要です。

## ファイル

- index.html：画面、3D描画、カメラ認識、ゲーム処理
- room.js：オンライン通信
- vendor/：Three.js、PeerJS、各ライセンス
- build.cjs、package.json、wrangler.jsonc：ビルド・公開設定

旧React版とそのサーバー・画像・テストは削除しました。
基本ルールと模擬通信テストは確認済み。実ブラウザー表示・実カメラ精度・別端末間の接続と遅延は未確認です。
