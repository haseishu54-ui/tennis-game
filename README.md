# 🎾 REAL TENNIS 3D — 写真のコートで動いて打つ v2.0

**起動すると新しい3Dモードが開きます。** 添付されたテニスコート画像を `public/court-reference.png` に保存し、「🖼️ 画像」視点の背景として使用しています。選手・ラケット・飛行中のボールは **Three.js / WebGLの立体オブジェクト**です。平面のコートに点を動かしているだけの2Dゲームではありません。

### 新しくできること

- **3D選手を動かしてボールを打つ**：ボールの X・Y（高さ）・Z（奥行き）を持つ物理計算。落下、ネット、ワンバウンド、ツーバウンド、アウト判定、着地点表示。
- **実際のサーブ**：`T` または「サーブ（トス）」でボールを投げ上げ、落ちる前に `Q / Space` または腕の振りでサーブ。
- **動作に応じた球筋**：前に走りながら打つ→速いトップスピン／後退しながら打つ→スライス／横移動→横回転／`E`→高いロブ／`F`→スマッシュ。サーブの飛距離もボールの高さとスイングのタイミングで変化。
- **走ると速い**：`Shift` を押したまま移動するとダッシュ。走るアニメーションも加速し、スタミナを消費。カメラの大きな動きによるダッシュにも対応。
- **5つのカメラ視点**：「画像」（アップロード画像の背景）、「追従3D」、「サイド」、「俯瞰」、「ボール追跡」。`V` で順番に切り替え。追従・ボール追跡は対象の移動に合わせてカメラ自体が動きます。
- **1人 vs CPU、CPU入りダブルス、伝説級のCPU、4人オンライン3Dダブルス**。旧2Dゲームと旧ダブルスも上のナビから選択できます。
- **既存のWebカメラ認識を再利用**：身体の左右/前後移動と腕を振る動作で移動・返球。手を上げる操作はサーブトス/ロブ。ブラウザのカメラ映像は端末上のみで解析し、オンライン転送しません。

### 動かす手順

Node.js 20.19+ / 22.12+ 以上を用意します（依存ライブラリに Three.js を追加）。

```bash
npm install
npm run dev
```

`http://localhost:3000` をブラウザで開いてください。HTMLファイルをダブルクリックするだけでは動きません。

最初はシングルスです。`WASD`/矢印で選手を移動 → `T` でトス → ボールが上がったら `Q` でサーブ → 飛んできた球に近づいて `Q` で返球。`Shift` ダッシュ、`E` ロブ、`F` スマッシュ、`V` 視点切替。画面下にクリック・タッチ用ボタンもあります。

オンラインは「🌐 オンライン4人」→ルームコードを入力→「ルームに参加」→「招待リンクをコピー」→4人が入室→1Pが「試合開始」。全員同じHTTPS公開サーバーを利用してください。元の4人ルーム通信を再利用します。ホストが球の物理計算を担当し、他の3人は各端末で自分の選手を操作します。通信があるため位置や球の見え方に遅延が生じることがあります。

> 注意：背景は**1枚の静止画像**です。「画像」視点では画像に3D人物・球を合成します。コートを横・上・後ろから見た映像は1枚の画像からは作れないため、他の視点では同じ形状を立体的に作り直した3Dコートを表示します。カメラ認識の精度はPC/スマホのカメラと照明の環境によって変わります。

- **ダブルスはコート外に大きな得点表示**：赤チームと黄チーム、参加座席、現在の状況、ラリー数を整理して表示。試合開始ボタンもコートより前に配置しました。
- **コートの白線とボールのコントラストを強化**：コートの左右に色の差を設け、ボールに濃い縁取りと光の効果を追加。着地点の目安も表示。
- **4人の人物にラベルとパワーゲージ**：文字は暗いプレートの上に表示し、プレイ中のキャラクターを見つけやすくしています。

この版は見た目の変更を中心とし、対戦・CPU・カメラ・ネットワーク処理はこれまでの仕様を保つ方針です。

## できること

- **元のゲーム**：ローカル2人プレイ / CPU（かんたん・ふつう・つよい） / 2人オンライン対戦。元のプレースタイル・努力値・さまざまなショットも残っています。
- **伝説級CPU**：元の試合の対戦相手に、最上位のCPUを追加。高い移動速度、正確な予測、ほぼミスなし。
- **4人オンラインダブルス**：1P＋3P（レッドチーム）対 2P＋4P（イエローチーム）。4人が別々のブラウザ・端末から参加。ホスト（1P）が試合開始・ボールの計算を担当し、残り3人は各自のキャラクターを操作できます。
- **ダブルス練習**：CPU3人を相手・味方にしたソロ練習と、強力な「伝説級AIに挑戦」。
- **カメラ体感操作**：カメラに全身の上半身を映し、左右への移動と腕の動きでプレイ（ロブ・ジャンプも対応）。精密な姿勢認識にはMediaPipeのモデルを使い、取得できない場合は簡易的な映像動作判定に切り替えます。**カメラ画像や音声をオンラインに送信しません。**
- **ダブルス追加アクション**：ダッシュ、ロブ、パワーゲージ、必殺スマッシュ、7点先取、連続ラリーと最高ラリー表示、タッチ操作。

## インストール / 起動

Node.js **20.19+ または 22.12+** を推奨します。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。最初の画面は従来のテニスゲームです。画面上部の **「👥 オンラインダブルス（4人）」** ボタンから新しいモードへ入れます。

> ⚠️ HTMLファイルを直接開いても動作しません。Node.jsまたはCloudflare Workersなどの配信サーバーが必要です。インターネット上の別の場所にいる人と遊ぶには、サーバーを**公開**し、全員が同じURLにアクセスする必要があります。

## ダブルスをオンラインで遊ぶ

1. ホストになる人が「オンラインダブルス（4人）」を開き、部屋コードを確認して「ルームに参加」を押します。
2. 「招待リンクをコピー」で他の3人に送ります。リンクは `?doubles=1&room=DB1234` のような形式です。
3. 残りの人はリンクを開いて「ルームに参加」を押します。全員 **同じ公開サーバー**に接続してください。
4. ロビーに **4/4人** 集まると1Pの「試合開始！」ボタンが使えるようになります。
5. レッド（1P/3P）とイエロー（2P/4P）で勝負。先に7点取れば勝利です。

オンラインダブルスは4人の参加が必要です。3人以下で遊びたいときは「CPUと練習」が使えます（練習はローカルのCPU対戦です）。

### ダブルスの操作

| 操作 | キーボード | カメラ操作 |
|---|---|---|
| 移動 | WASD / 矢印 | 体を左右に動かす、カメラに近づく・離れる |
| 通常ショット | Q / Space / / | 手・腕を振る |
| ロブ | E / `\` | 両手を高く上げて腕を動かす |
| パワースマッシュ | F（パワー90以上） | ジャンプ＋手を振る（カメラ認識時） |
| ダッシュ | Shift | 大きめの左右移動 |

ショットを打つごとにパワーゲージが増え、90以上で強力なスマッシュを打てます。スマホ・タブレット向けに画面下にタッチボタンも付けています。

**元のゲーム**：A / D=移動、W=ジャンプ、Q=ショット、E=ロブ。CPU戦と2人オンラインでは矢印キーも使えます。Shiftで短い高速移動ができます。

## カメラモードの使用方法

1. **PCのカメラ、またはスマホのカメラ**が使用できることを確認します。
2. 元のゲームは画面上部の「📷 カメラ体感操作」、ダブルスは「📷 カメラ操作を使う」を押します。
3. 「カメラ開始」→ブラウザのカメラ使用を許可します。
4. 画面中央に立つと身体の位置をキャリブレーション。立ち位置が変わったら「中心を再設定」を押します。
5. 腕を振ると打球、体を動かすと移動します。必要ならキーボードも併用できます。

高精度の姿勢認識には、初回実行時に外部サービス（jsDelivrのMediaPipe JS/WASM、Google配信の姿勢認識モデル）への**ネット接続が必要**です。失敗した場合は「簡易動作認識」に自動切り替えます。簡易モードは動きの量による判定のため、照明や背景によって精度が落ち、ロブ・ジャンプなどすべての動きを認識できるわけではありません。

**カメラの注意**：HTTPS または `http://localhost` で起動してください。通常の LAN 内 `http://192.168...` では、多くのブラウザでカメラ許可が出ないため、HTTPSの公開URLを使います。カメラ映像はPC・スマホ内だけで処理し、録画もWebSocket送信もしません。壁や家具から距離をとって小さい動きでプレイしてください。

## Cloudflare Workers で公開する

Cloudflare Workers + Durable Objects を使い、WebSocketルームを動かします。**Cloudflare Pagesの静的サイトだけではオンライン対戦は動きません。**

```bash
npm install
npx wrangler login
npm run cf:deploy
```

Workers の公開URLに全員が接続すれば、2人対戦と4人ダブルスで遊べます。Workers無料枠にはリクエスト数などの制限があります。

## Render / Railway / VPS など Node.js サーバー

```bash
npm install
npm run start:prod
```

`PORT` 環境変数に対応。HTTPSで公開する場合、WebSocketも自動的にWSSを使用します。
